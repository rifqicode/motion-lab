# Illustration art direction

Read the [Style Bible](style-bible.md). Select a preset, perspective and subject hierarchy before drawing. Assets use palette tokens from `src/illustration/style.ts`; illustration data selects `education`, `botanical`, or `midnight`.

For every narration sentence, write the visible evidence and what changes on screen. Favor object interaction over caption-only explanation. Decide which object leads and which elements support it. Coffee is a worked example, not a universal three-scene template.

Use `visual: 'illustrated'` for layered vector scenes; use `graph` and its existing Three.js assets when genuine spatial depth matters. Preserve older visual kinds. The renderer includes a default title/caption layout; its labels come from `eyebrow` and `edition`, not the coffee story. Move or extend the layout when a new story needs another composition.
