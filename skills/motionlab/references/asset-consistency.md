# Asset consistency review

Check the family together before approving individual shots:

- Same token roles, outline scale and cap/join language?
- Same light direction and shading restraint?
- Same frontal/elliptical perspective and relative wall/handle thickness?
- Identifying details visible at intended size?
- Independent pivots, layers and masks retained through registration?
- Material distinctions clear, with restrained gradients and no glass UI or neon effects?
- Repeated characters retain face proportions and expressions?

The compiler checks structure and references. It does not prove visual consistency, physical accuracy, SVG path validity, contrast or screen bounds. Inspect actual frames and record failures and corrections in the QA report. Test each new palette; token substitution alone cannot guarantee readability.
