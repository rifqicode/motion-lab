# P0 Rendering validation

Target: 1080×1920, 60 fps, 15 seconds (900 frames), H.264 MP4.

Run `npm install`, `npm run typecheck`, `npm run render`, and `node scripts/validate-video.mjs` (requires ffprobe).

GitHub Actions **Render MP4** runs on pull requests and manually. Download the `motion-lab-1080p60` artifact from the workflow run.

**Known limitations:** Dependency installation and rendering have not yet been validated. A committed lockfile is pending: the current environment cannot reach npm registry. Until a lockfile is generated and committed, CI uses `npm install`, not `npm ci`, and builds are not fully reproducible. Visual quality and absence of blank frames require manual review; metadata validation alone cannot establish them.
